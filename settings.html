Usage

To use the AI Text Rewriter:

  1. Select text in any editable field (input, textarea, or rich text editor).
  2. Right-click on the selected text.
  3. Choose Rewrite with AI and select a rewrite mode.
  4. Click a suggestion to select it, then click Replace Selected Text.
